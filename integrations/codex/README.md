# Personal Codex plugin source

`ananda-control` is a copy of the personal plugin installed on this machine. Its command points to `C:\Users\fahad\Applications\Ananda Control\ananda-control.exe --mcp`.

For another installation, update `.mcp.json` with the real executable path before installing the plugin into that user's marketplace. The bridge is part of the application executable; no extra runtime or server installation is needed.

See `docs/AGENT-CONTROL.md` at the repository root for tools, access controls and protocol details.
